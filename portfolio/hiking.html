// VICTORIAN HIKING HUB

A trail discovery platform built with modular JavaScript and Mapbox GL, grounded in UX research.

The Victorian Hiking Hub brings together interactive trail maps, gear checklists, and trip planning tools into a single cohesive interface. The project began with extensive user research to understand how hikers actually plan trips — then translated those findings into an information architecture that reduces friction at every step.
